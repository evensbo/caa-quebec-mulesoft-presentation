# CAA Québec - MuleSoft Strategy POV Presentation

Interactive presentation showcasing the MuleSoft integration strategy for CAA Québec.

## Features

- 6 interactive slides covering integration architecture
- Bilingual support (English/French)
- Interactive scenario simulations
- Full-screen presentation mode
- Keyboard navigation support

## Deployment

This site is deployed on GitHub Pages at: https://ebonifasse.github.io/caa-quebec-mulesoft-presentation/

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```

## Keyboard Shortcuts (Presentation Mode)

- `Space` or `→` - Next slide
- `←` - Previous slide
- `Escape` - Exit presentation mode

## Technology Stack

- React 18
- Vite
- Tailwind CSS
- GitHub Pages
